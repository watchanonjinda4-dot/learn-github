• Cloud Storage: It acts as an online home for code projects, using the Git version control system to track changes over time.
• Collaboration Hub: Multiple people can work on the same project at once, propose changes, and review code before adding it to the main project.
• Microsoft Subsidiary: Owned by Microsoft since 2018, it serves over 180 million developers worldwide.
Key Features
• Repositories: Folders or storage spaces that hold all project files and their complete revision history.
• Pull Requests: Proposals to review and merge changes from one section of code into another.
• GitHub Copilot: An AI-powered coding assistant that helps write, chat about, and fix code.
• GitHub Actions: Built-in automation tools to test and deploy software.
• Issues and Projects: Built-in tools for tracking bugs, planning tasks, and managing workflows.
